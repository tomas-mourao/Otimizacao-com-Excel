# Caso BoaPesca

Projeto da unidade curricular **Otimização para Ciência de Dados**: caso **BoaPesca**. Modelo de Programação Linear para minimizar o custo de produção e distribuição de conservas de sardinha de quatro fábricas para cinco regiões de Espanha, resolvido no Excel (Solver), com análise do plano ótimo e de sensibilidade.

## Conteúdo
- `grupo31.docx` – relatório (formulação, resolução, análise de sensibilidade e proposta de alteração)
- `grupo31.xlsx` – modelo e resolução no Excel
