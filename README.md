# BoaPesca – Linear Programming Optimization

Linear Programming model that minimizes the production and distribution cost of canned sardines shipped from **four factories to five regions of Spain**, solved in Excel with Solver.

> **Course:** Optimization for Data Science · BSc in Data Science, ISCTE · Year 1, Semester 2

## What's included
- Mathematical formulation of the problem (decision variables, objective function, constraints)
- Solution with Excel Solver and analysis of the optimal plan
- Sensitivity analysis
- Proposed change to the model and its impact

## Tech stack
Excel · Solver

## Project structure
| File | Description |
|------|-------------|
| `solver_model.xlsx` | Model and solution in Excel |
| `report.docx` | Report: formulation, solution, sensitivity analysis and proposed change |

> The report is written in Portuguese.
